# 架构与边界

## 当前：只有静态演示

```text
浏览器
  index.html + styles.css + mark.svg
  app.mjs ──────→ views.mjs        渲染与转义
      │
      ├────────→ floating.mjs     拖动阈值与视口限制
      └────────→ data.mjs         纯状态转换 + mockAdapter
                                     └── 内存虚构数据

scripts/preview.mjs → 只向 localhost 提供 dist/ 静态文件
```

`dist/` 保留为手写源码和静态发布根目录，无 bundler、无编译过程。`scripts/`、`tests/`、`docs/` 和配置示例不应作为网站根目录暴露。当前预览与 CI 不注册站点、不发布、不部署。

- `app.mjs` 处理事件、忙碌保护、演示标记和模态焦点；不访问真实 API。
- `data.mjs` 提供异步形状的 `mockAdapter`、初始状态和纯 `transition`；这是未来替换边界，不是安全边界。
- `views.mjs` 渲染 HTML，动态字符串通过 `escapeHTML` 转义。
- `floating.mjs` 是可单测的拖动数学。浮窗是各页面共用控件，不恢复独立服务器页面。
- 本人角色、公共玩家名单、榜单样例各自独立；不能由本人 3 个角色推导全服在线或排名。

演示 `admin` 只保存 `arad-admin-demo-v2=admin` 到当前标签页 `sessionStorage`。任何人都能修改前端代码或这个值，所以绝不能用于真实授权。

## 后续：独立门户后端（尚未实现）

```text
浏览器 ──同源 HTTPS──→ 独立门户后端（例如 Go）
                         ├── 独立 Web 会话、逐请求授权、限流
                         ├── 本人角色只读服务
                         ├── 最小化公共状态/名单与榜单
                         └── 只读数据适配层 → 已确认且获授权的数据来源
```

首期只需要一个独立后端进程，不需要微服务、前端框架迁移或伪装成已接入的 mock HTTP 服务。后端可继续提供 `dist/` 或由同源反向代理提供静态文件；当前 Node 预览不要作为生产服务。

真实登录方案须先确认账号来源。Web 会话必须独立于游戏会话，不直接套用可能轮换游戏 token、断开游戏连接的登录流程。不要仅凭接口名字认定安全；实际部署版本的登录副作用必须重新核实。首期不接入 GM，也不把数据库/服务凭据发送给浏览器。

## 必须守住的安全边界

1. 服务器从已认证会话派生账号身份，不信任客户端提交的 `accountId`、登录名或角色归属判断。
2. 每次读取角色、属性、装备、位置与个人深渊数据都验证归属，拒绝跨账号请求。
3. 使用独立、可注销的服务端 Web 会话；生产 Cookie 设置 Secure、HttpOnly、适当 SameSite，并为会话/状态变更实施 CSRF 防护。具体实现待后端设计验证。
4. 只读数据连接使用最小权限；游戏账户库、门户会话存储分离。查询不修改存档，不替换游戏 token，不踢游戏连接。
5. 公共玩家名单不带账号 ID、余额、装备、个人深渊记录；默认是否公开由服务端策略决定，不因名字 `admin` 获得额外能力。
6. 接入失败保留未知/错误状态，不自动回退为看似实时的样例。业务日与样例日期、观测时间与刷新时间必须区分。

## 验证层次

- `prototype.test.mjs`：渲染、转义、状态、样例隔离、计次和排名语义。
- `admin-login.test.mjs`：轻量 DOM 事件桩，覆盖重复提交、刷新/退出、拖动、关闭/Esc、签到提示、榜单切换。
- `preview.test.mjs`：真实 localhost HTTP、所有静态资源与 MIME、HEAD/404/405、路径/编码/隐藏文件/符号链接、CLI 启停。
- `npm run check`：语法与 JSON 检查后执行全套测试。CI 在 Node 22/24 上执行同一命令，不部署。
- 浏览器验收仍要检查桌面/窄屏、触摸拖动、键盘焦点、反复关闭/切换和减少动画；单元测试不证明真实浏览器无缺陷。
